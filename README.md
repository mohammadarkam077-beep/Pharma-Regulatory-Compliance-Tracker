# Pharma Regulatory Compliance Tracker

AI-powered healthcare regulatory workflow and compliance management platform built using Python, Streamlit, SQLite, and analytics-driven operational workflows.

---

# Overview

The Pharma Regulatory Compliance Tracker is designed to streamline pharmaceutical and healthcare regulatory operations by centralizing:

- Regulatory document management
- Compliance monitoring
- SOP tracking
- Expiry prediction
- AI-assisted document querying
- Workflow automation
- Smart compliance alerts

The platform helps reduce manual tracking inefficiencies commonly found in pharmaceutical regulatory workflows.

# Installation

## Clone Repository

```bash
git clone https://github.com/mohammadarkam077-beep/Pharma-Regulatory-Compliance-Tracker.git
```

## Navigate to Project

```bash
cd Pharma-Regulatory-Compliance-Tracker
```

## Create Virtual Environment

```bash
python -m venv venv
```

## Activate Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux/Mac

```bash
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# Run Application

```bash
streamlit run app.py
```
