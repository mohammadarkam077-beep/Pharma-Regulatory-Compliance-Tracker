# 🌟 Overview

The **Pharma Regulatory Compliance Tracker** is an AI-powered healthcare workflow platform designed to streamline pharmaceutical compliance and regulatory operations.

The system combines:

✅ Regulatory workflow management  
✅ AI-assisted document querying  
✅ Compliance monitoring  
✅ Smart alerts & notifications  
✅ SOP management  
✅ Analytics dashboards  
✅ Operational automation  

This platform was built to reduce manual inefficiencies commonly found in pharmaceutical regulatory environments.

# 🚀 Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/mohammadarkam077-beep/Pharma-Regulatory-Compliance-Tracker.git
```

---

## 2️⃣ Navigate to Project

```bash
cd Pharma-Regulatory-Compliance-Tracker
```

---

## 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

---

## 4️⃣ Activate Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux/Mac

```bash
source venv/bin/activate
```

---

## 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Application

```bash
streamlit run app.py
```
